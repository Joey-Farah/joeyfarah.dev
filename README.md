# joeyfarah.dev

Interactive visual resume — boots into a terminal sequence, expands
into a bento grid of professional work and personal projects, and
renders a scroll-driven ERD diagram from seed data.

**Stack:** React 18 · Vite · TypeScript · Tailwind · Framer Motion ·
Rive (client) · Express · Mongoose · Zod (server) · MongoDB Atlas ·
ports-and-adapters architecture · hosted on Railway.

Live at [joeyfarah.dev](https://joeyfarah.dev).
